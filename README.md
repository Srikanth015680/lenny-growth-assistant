
# The Lenny Growth Assistant

A RAG-based chat assistant for searching Lenny's Podcast transcripts. It is built for product managers and growth teams who want answers based on the transcript data, with the relevant episode and timestamp included.

The app uses Next.js, FastAPI, PostgreSQL with pgvector, and Ollama. Anthropic is also supported as an optional provider.

## Features

- Search podcast transcripts using vector search
- Answers based on retrieved transcript content
- Episode and timestamp citations
- Saved chat sessions
- Streaming responses with SSE
- Ship30-style essay generation
- Markdown and HTML artifact generation
- Ollama support
- Optional Anthropic support
